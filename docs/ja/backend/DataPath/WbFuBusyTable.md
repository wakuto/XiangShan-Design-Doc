## 機能

WbFuBusyTableモジュールの主な機能は、異なる実行ユニットのビジーテーブルと書き戻しポートの間の相互作用を管理および同期することです。

主なプロセスは以下の通りです。

1. 整数スケジューラ、浮動小数点スケジューラ、ベクトルスケジューラ、メモリアクセススケジューラからのビジーテーブル情報をタイプ別にマージして、グローバルビジーテーブルを作成します。
2. グローバルビジーテーブルを実行ユニットのパラメータにバインドし、パラメータから各書き戻しポートの最大遅延と決定性フラグ（機能ユニットの実行遅延が決定論的かどうか）を取得し、遅延設定に基づいてハードウェアビジーテーブルを生成します。
3. 書き戻し物理レジスタのタイプに基づいて、実行ユニットが指定された書き戻しポートに接続されているかどうかを判断します。
4. 各実行ユニットのビジー状態を書き戻しポートのビジーテーブルにマージします。
5. 書き戻しポートのビジーテーブルを各スケジューラの発行キューに分配します。

### 機能ユニットビジーテーブル FuBusyTable

機能ユニットビジーテーブルは、各機能ユニットの異なる時点でのビジー状態を記録します。決定論的な遅延を持つ機能ユニットのみが機能ユニットビジーテーブルを持ち、ビット幅は機能ユニットの実行遅延長に等しくなります。各ビットは特定の時点に対応し、「1」はその機能ユニットがその時点でビジー状態であることを示し、「0」はアイドル状態であることを示します。

### 機能ユニットビジーテーブル書き込み FuBusyTableWrite

機能ユニットビジーテーブル書き込みの主な機能は、機能ユニットビジーテーブルの状態を更新することです。発行キューからのデキュー信号（deqResp）、og0ステージ処理完了後に返される応答信号（og0Resp）、og1ステージ処理完了後に返される応答信号（og1Resp）など、さまざまな応答信号を受け取ります。これらの信号の有効性と機能ユニットのタイプに基づいて、ビジーテーブルを更新します。命令が正常に発行されると、応答信号内の機能ユニットタイプと遅延情報に基づいて、ビジーテーブルの対応する位置が「1」に設定され、その機能ユニットがビジー状態であることを示します。og0またはog1ステージで命令の発行が失敗した場合、応答信号内の機能ユニットタイプと遅延情報に基づいて、ビジーテーブルの対応する時点の値がクリアされ、その機能ユニットがアイドル状態であることを示します。

### 機能ユニットビジーテーブル読み取り FuBusyTableRead

機能ユニットビジーテーブル読み取りは、ビジーテーブルと機能ユニットタイプを処理することにより、どの命令が対応する機能ユニットを使用できるかを示すマスクを生成します。
