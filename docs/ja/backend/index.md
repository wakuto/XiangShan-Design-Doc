# バックエンド

この章では、XiangShanプロセッサのバックエンド設計について詳しく説明します。バックエンドは、デコードされた命令を受け取り、実行し、結果をコミットするまでの一連の処理を担当します。

この章で説明するコンポーネントは以下の通りです。

- **制御ブロック**: デコード、リネーム、ディスパッチ、リオーダバッファなど、命令のフローを制御します。
- **データパス**: 実行ユニット間のデータ転送とバイパスネットワークを管理します。
- **スケジューリングと発行**: 命令を発行キューでスケジューリングし、実行ユニットに発行します。
- **実行ブロック**: 整数、浮動小数点、ベクトル演算などを実行します。
- **機能ユニット**: 各種演算を実行する具体的なユニットです。
- **その他**: CSR、HPM、デバッグモジュールなどが含まれます。
