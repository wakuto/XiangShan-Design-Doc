# バックエンド全体概要

Backend は香山プロセッサの後段を構成し、命令デコード(Decode)、リネーム(Rename)、ディスパッチ(Dispatch)、スケジューリング(Schedule)、発行(Issue)、実行(Execute)、書き戻し(Writeback)、リタイア(Retire)といった複数のコンポーネントで構成されます（図[@fig:backend-overall]）。

![バックエンド全体フレームワーク](figure/backend.svg){#fig:backend-overall}

## 基本仕様

- 6 命令幅のデコード／リネーム／ディスパッチ
	- 整数レジスタファイル 224 エントリ、浮動小数点レジスタファイル 192 エントリ、ベクトルレジスタファイル 128 エントリ
	- Move 命令削除
	- 命令融合
- 160 エントリの ROB
	- ROB 圧縮をサポート（1 エントリ最大 6 uop）
	- 1 サイクルあたり最大 8 エントリリタイア
	- スナップショット復元
- Rename Buffer
	- 256 エントリの RAB
	- 命令コミットとレジスタ書き戻し
- 整数・浮動小数点・ベクトル演算
