# 分岐予測ユニット (BPU)

この章では、XiangShanプロセッサの分岐予測ユニット（BPU）の設計について詳しく説明します。BPUは、プログラムの実行フローを予測し、命令パイプラインの効率を向上させるための重要なコンポーネントです。

この章で説明するコンポーネントは以下の通りです。

- **uFTB (マイクロFTB)**: 高速な分岐ターゲット予測を提供します。
- **FTB (分岐ターゲットバッファ)**: 分岐命令のターゲットアドレスを格納します。
- **TAGE-SC**: 高度な分岐予測アルゴリズムです。
- **ITTAGE**: TAGEを改善した分岐予測器です。
- **RAS (リターンアドレススタック)**: 関数呼び出しからのリターンアドレスを予測します。
- **Composer**: 複数の予測器からの結果を統合します。
