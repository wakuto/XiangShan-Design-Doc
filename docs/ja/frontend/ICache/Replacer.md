# Replacerサブモジュール ドキュメント

PLRU置換アルゴリズムが採用されています。各フェッチが連続するダブルラインにアクセスする可能性があることを考慮して、奇数アドレスと偶数アドレス用に2つのリプレーサが設定され、アドレスのパリティに基づいてタッチおよびビクティム操作中にそれぞれのリプレーサを更新します。

![PLRUアルゴリズム図](../figure/ICache/Replacer/plru.png)

## touch

リプレーサには、デュアルラインアクセスをサポートするために2つのタッチポートがあり、タッチ操作はアドレスの奇数/偶数に基づいて対応するリプレーサに分配されます。

## victim

リプレーサにはビクティムポートが1つしかありません。これは、一度に1つのMSHRのみがSRAMに書き込むためです。同様に、アドレスのパリティに基づいて対応するリプレーサからウェイマスクを取得します。リプレーサを更新するためのタッチ操作は、次のサイクルで実行されます。
