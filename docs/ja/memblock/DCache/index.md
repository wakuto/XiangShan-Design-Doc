## 機能説明
### 特徴1: ロード要求の処理

通常のロード要求の場合、DCacheはLoadUnitからロード命令を受け取った後（実装されているロードパイプラインは3本あり、3つのロード要求を並行して処理できます）、計算されたアドレスに基づいてtagArrayとmetaArrayを検索し、ヒットしたかどうかを比較判断します。キャッシュラインにヒットした場合はデータを返して応答します。ミスした場合はMSHR（MissEntry）エントリを割り当て、要求をMissQueueに渡します。MissQueueはL2キャッシュにAcquire要求を送信してリフィルデータを取得し、L2キャッシュからのヒント信号を待ちます。l2_hintが到着すると、MainPipeにリフィル要求を発行し、置き換えウェイを選択してリフィルデータブロックをストレージユニットに書き込み、同時に取得したリフィルデータをLoadUnitにフォワーディングして応答を完了します。置き換えられたブロックを書き戻す必要がある場合は、WritebackQueueでL2にRelease要求を送信して書き戻します。
ミスした要求がMSHRエントリの割り当てに失敗した場合、DCacheはMSHR割り当て失敗信号をフィードバックし、LoadUnitとLoadQueueReplayがそのロード要求を再スケジュールします。

### 特徴2: ストア要求の処理

通常のストア要求の場合、DCacheはStoreBufferからストア命令を受け取った後、MainPipeパイプラインを使用してアドレスを計算し、タグとメタを検索してヒットしたかどうかを判断します。キャッシュラインにヒットした場合は、DCacheデータを直接更新して応答を返します。ミスした場合はMSHRを割り当てて要求をMissQueueに渡し、L2にDcacheにリフィルする元のターゲットデータラインを要求し、L2キャッシュからのヒント信号を待ちます。l2_hintが到着すると、MainPipeにリフィル要求を発行し、置き換えウェイを選択してリフィルデータブロックをDCacheストレージユニットに書き込み、そのデータに対するストア操作が完了した後、StoreBufferに応答を返します。置き換えられたブロックを書き戻す必要がある場合は、WritebackQueueでL2にRelease要求を送信して書き戻します。
ミスした要求がMSHRエントリの割り当てに失敗した場合、DCacheはMSHR割り当て失敗信号をフィードバックし、StoreBufferが後でそのストア要求を再スケジュールします。

### 特徴3: アトミック命令の処理

アトミック命令については、DCacheのMainPipeパイプラインが命令の演算と読み書き操作を完了し、応答を返します。データがミスした場合は同様にMissQueueに要求を発行し、データを取得した後にそのアトミック命令の実行を続行します。AMO命令については、まず演算操作を完了し、次に結果を書き込みます。LR/SC命令については、そのreservation setを設定/チェックします。アトミック命令の実行中、コアはDCacheに他の要求を発行しません（Memblockドキュメントを参照）。

### 特徴4: プローブ要求の処理

プローブ要求の場合、DCacheはL2キャッシュからプローブ要求を受け取った後、MainPipeパイプラインに入り、プローブされたデータブロックの権限を変更し、ヒットした次のサイクルで応答を返します。

### 特徴5: 置き換えと書き戻し

DCacheはライトバックおよびライトアロケートの書き込みポリシーを採用しており、replacerモジュールがミス要求のリフィル後に置き換えられるブロックを計算して決定します。random、lru、plruの置き換えポリシーを設定でき、デフォルトではplruポリシーが使用されます。置き換えブロックを選択した後、それをWritebackQueueキューに入れ、L2キャッシュにRelease要求を発行します。一方、ミスした要求はL2からターゲットデータブロックを読み取った後、対応するキャッシュラインにフィルされます。
