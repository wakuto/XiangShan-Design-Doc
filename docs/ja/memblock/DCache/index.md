# データキャッシュ (DCache)

この章では、XiangShanプロセッサのデータキャッシュ（DCache）の設計について詳しく説明します。DCacheは、CPUが頻繁にアクセスするデータを高速に供給するためのキャッシュメモリです。

この章で説明するコンポーネントは以下の通りです。

- **ロードパイプライン**: ロード命令のパイプライン処理。
- **ミスキュー**: キャッシュミスしたメモリアクセス要求を管理します。
- **プローブキュー**: キャッシュの一貫性を保つためのプローブ要求を管理します。
- **メインパイプライン**: DCacheのメインパイプライン処理。
- **ライトバックキュー**: Dirtyなキャッシュラインをメモリに書き戻す要求を管理します。
- **エラー処理**: エラー検出と訂正、およびカスタム障害注入について説明します。
