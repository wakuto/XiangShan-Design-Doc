# 3次モジュール プリフェッチャー

プリフェッチャーは、以下のモジュールを指します。

* L2TlbPrefetch prefetch

## 設計仕様

1. Next-lineプリフェッチアルゴリズムをサポート
2. 重複した履歴要求のフィルタリングをサポート

## 機能

### プリフェッチ要求の発行

以下の2つの条件のいずれかが満たされると、プリフェッチ要求が発行されます。

1.  ページキャッシュミス
2.  ページキャッシュヒットだが、ヒットしたのがプリフェッチされたエントリ

プリフェッチャーはNext-Lineプリフェッチアルゴリズムを採用しています。プリフェッチされた結果はページキャッシュに保存され、L1 TLBには返されません。ページテーブルウォーカーのメモリアクセス能力が限られているため、プリフェッチ要求はページテーブルウォーカーやミスキューには入らず、直接破棄されます。プリフェッチ要求が最終レベルのページテーブルのみを欠いている場合、LLPTWにアクセスできます。さらに、プリフェッチャーにはフィルターバッファーが追加されており、重複したプリフェッチ要求をフィルタリングします。

### 重複した履歴要求のフィルタリング

重複した要求によってL2 TLBのリソースが無駄になるのを避け、プリフェッチャーの利用率を向上させるために、セクション5.3.11.2で説明されている2つの条件が満たされてプリフェッチ要求が発行されると、同じアドレスに対するプリフェッチ要求がすでに発行されているかどうかがチェックされます。もしそうなら、新しく受信したプリフェッチ要求は破棄されます。現在のプリフェッチャーモジュールは、最新の4つの要求をフィルタリングします。

プリフェッチャーはnext-lineプリフェッチャーであり、インターフェースのタイミングは比較的単純なので、ここでは詳述しません。
