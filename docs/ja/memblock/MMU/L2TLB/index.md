# L2 TLB

この章では、XiangShanプロセッサのL2 Translation Lookaside Buffer（L2 TLB）の設計について詳しく説明します。L2 TLBは、L1 TLBでミスが発生した際に、より大きな範囲のアドレス変換をキャッシュする役割を担います。

この章で説明するコンポーネントは以下の通りです。

- **ページキャッシュ**: ページテーブルエントリをキャッシュします。
- **ページテーブルウォーカー (PTW)**: ページテーブルを辿ってアドレス変換を行います。
- **最終レベルページテーブルウォーカー (LLPTW)**: 最終レベルのページテーブルウォークを担当します。
- **ハイパーバイザページテーブルウォーカー (HPTW)**: ハイパーバイザ環境でのアドレス変換をサポートします。
- **ミスキュー**: L2 TLBのミス要求を管理します。
- **プリフェッチャ**: ページテーブルエントリを事前にフェッチします。
- **s2tlb**: 2段目のアドレス変換（ゲスト仮想→ゲスト物理）のためのTLBです。
- **tlb**: 汎用のTLBコンポーネントです。
