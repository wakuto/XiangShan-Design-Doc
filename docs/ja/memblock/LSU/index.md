# ロード・ストアユニット (LSU)

この章では、XiangShanプロセッサのロード・ストアユニット（LSU）の設計について詳しく説明します。LSUは、メモリアクセス命令（ロードおよびストア）を処理し、データキャッシュおよびメモリシステムとのインタフェースを担当します。

この章で説明するコンポーネントは以下の通りです。

- **ロードユニット**: ロード命令を実行します。
- **ストアユニット**: ストアアドレスを計算します。
- **ストアデータユニット**: ストアデータを処理します。
- **アトミック操作ユニット**: アトミック命令を処理します。
- **Uncache処理ユニット**: Uncache領域へのアクセスを処理します。
- **ストアコミットバッファ**: ストア命令をコミットします。
- **非整列アクセスユニット**: 非整列メモリアクセスを処理します。
- **ベクトルメモリアクセス**: ベクトルロード/ストア命令を処理します。
- **ロード・ストアキュー (LSQ)**: メモリアクセス命令の順序を管理します。
