# ロード・ストアキュー (LSQ)

この章では、XiangShanプロセッサのロード・ストアキュー（LSQ）の設計について詳しく説明します。LSQは、ロード命令とストア命令の順序を管理し、メモリ依存関係のチェックと解決を行います。

この章で説明するコンポーネントは以下の通りです。

- **ロードキュー**: ロード命令を管理します。
- **Read-After-Read (RAR) チェック**: ロード間の依存関係をチェックします。
- **Read-After-Write (RAW) チェック**: ロードとストア間の依存関係をチェックします。
- **ロードリプレイキュー**: 依存関係違反などでリプレイが必要なロード命令を管理します。
- **Uncacheロードユニット**: Uncache領域へのロードを処理します。
- **ロード例外バッファ**: ロード命令で発生した例外を管理します。
- **ストアキュー**: ストア命令を管理します。
