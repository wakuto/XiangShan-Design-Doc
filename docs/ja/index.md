# XiangShan プロセッサデザインドキュメント

XiangShan は、RISC-V 命令セットアーキテクチャをサポートするオープンソースの高性能プロセッサです。このドキュメントは、XiangShan プロセッサの設計に関する詳細を記述しています。

このドキュメントは、プロセッサのアーキテクチャ、マイクロアーキテクチャ、および実装の詳細を理解するためのガイドです。

ドキュメントの構成は以下の通りです。

- **フロントエンド**: 命令フェッチ、分岐予測、および命令デコードを担当します。
- **バックエンド**: 命令の実行、スケジューリング、およびリタイアを担当します。
- **メモリシステム**: ロード/ストア操作、キャッシュ、およびメモリ管理を担当します。
- **キャッシュサブシステム**: L2キャッシュおよびその他のキャッシュコンポーネントの詳細を記述します。
